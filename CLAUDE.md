# Правила для Claude в этом проекте

## Видео
- Каждый раз, когда создаёшь видео, обязательно делай к нему хорошую обложку (превью/thumbnail):
  - яркая, цепляющая, крупный план главного персонажа с выразительной эмоцией;
  - короткий крупный заголовок (2–5 слов), читаемый даже на маленьком экране телефона;
  - формат под платформу: 1280×720 (16:9) для обычных YouTube-видео, 1080×1920 (9:16) для Shorts;
  - сохраняй обложку рядом с видео (тот же файл с суффиксом `_cover.png` / `.jpg`)
    и вшивай её в mp4 как attached picture, чтобы она показывалась как превью файла.
- Проект: комедийный сериал «Апа против ИИ», язык — русский, видео лежат в `video/`.
